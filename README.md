## Learning Path

A practical progression is:

1. Begin with **Fawkes Setup Lab** to establish the challenge environment.
2. Practice reconnaissance with **Recon Radar**, **Spellbound Service Sweep**, and **Fawkes Network Hunt**.
3. Continue with **Enum the Weak Spots** to develop systematic enumeration habits.
4. Explore **Fawkes Find the Hidden Clues** and the Horcrux-themed challenges.
5. Study **Fawkes Packet Trail** for traffic-analysis practice.
6. Move into **Fawkes Spellbound Overflow 2** and **Fawkes LPE Forge** for vulnerability and privilege-boundary concepts.
7. Finish with **Fortress Hardening Lab** and consider defensive controls for the issues encountered.

## How to Use the Labs

1. Choose a challenge from the index.
2. Read the lab instructions and identify its learning objective.
3. Work only inside the authorized CTF environment.
4. Document observations, commands, evidence, and findings.
5. Explain the security concept behind each discovery.
6. Consider detection and mitigation strategies where appropriate.
7. Keep personal notes so each challenge contributes to a reusable security methodology.

Only perform security testing against systems where you have explicit authorization.
